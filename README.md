#  Gemini Clone

> A modern AI Chat App powered by **Google Gemini API** built using **React + Vite**

## 🌟 What is Gemini Clone?

Gemini Clone is a clean and user-friendly chatbot interface built using **React**.
It connects to **Google Gemini API** and gives smart AI responses — similar to the original Gemini chatbot.

Perfect for learning:

✔ API integration
✔ Chat UI design
✔ Modern React development

## ⚙️ Getting Started

Follow these steps to run it locally 👇

### 1️⃣ Clone the project

```bash
git clone https://github.com/your-username/gemini-clone.git
```

### 2️⃣ Move into the project

```bash
cd gemini-clone
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Set up your API Key

Create `.env` file in root folder:

```
VITE_GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
```

> API key can be generated from **Google AI Studio**

### 5️⃣ Run the app

```bash
npm run dev
```

Then open your browser at:
👉 [http://localhost:5173/](http://localhost:5173/)
